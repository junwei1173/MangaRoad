**MangaRoad** is a fun and interactive web application for manga lovers to discover, bookmark, rate, and share their favorite manga.  
Built with React for the frontend and Node.js/Express for the backend, MangaRoad offers a seamless manga browsing experience with social features.

## Features

- Search and browse manga titles with detailed info  
- Bookmark your favorite manga for easy access  
- Rate and review manga you’ve read  
- Follow other users to see their bookmarks and ratings  
- Responsive and retro-inspired UI design  

---

## Tech Stack

- **Frontend:** React, React Router, CSS (Retro-themed styling)  
- **Backend:** Node.js, Express, MongoDB, Mongoose  
- **Authentication:** JSON Web Tokens (JWT), bcrypt for password hashing  
- **Deployment:** Vercel (frontend), Render (backend)
